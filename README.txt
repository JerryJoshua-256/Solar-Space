ORBIT — Interactive 3D Solar System

A fully procedural WebGL solar system experience.

Features
- Sun at the center with glowing corona
- All 9 planets (Mercury → Pluto) orbiting with correct relative feel
- Planet names float above each world
- Drag / touch to orbit the camera
- Click / tap a planet → smooth zoom into that planet’s system
- See the planet up close with its major moons orbiting it
- Double-tap → open a detail panel with facts about the planet
- Triple-tap → return to the full solar system
- Fully responsive on phones, tablets and desktops

Deploy to Netlify (free)
1. Unzip so you see the folder containing index.html
2. Go to https://app.netlify.com/drop
3. Drop the folder
4. Get a live *.netlify.app URL

Tips
- Quality tiers: add ?q=low or ?q=mobile to the URL if needed
- Works offline once loaded
- Requires a browser with WebGL
